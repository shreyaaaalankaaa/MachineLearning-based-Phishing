API Documentation

RESTful API for integrating PhishGuard's machine learning-powered phishing detection into your applications.

Overview

The PhishGuard API provides endpoints for:

  • Single URL phishing detection
  • Batch URL analysis
  • Model information and status
  • Model training with custom datasets
Base URL: All API endpoints are relative to your application's base URL. For local development, this would be http://localhost:5000

Authentication

Currently, the API does not require authentication. For production deployments, consider implementing API keys or other authentication mechanisms.

Code Examples

JavaScript (Fetch API)

// Single URL prediction
async function checkURL(url) {
    try {
        const response = await fetch('/api/predict', {
            method: 'POST',
            headers: {
                'Content-Type': 'application/json',
            },
            body: JSON.stringify({ url: url })
        });
        
        const result = await response.json();
        
        if (result.success) {
            console.log('Prediction:', result.data.prediction);
            console.log('Confidence:', result.data.confidence);
        } else {
            console.error('Error:', result.error);
        }
    } catch (error) {
        console.error('Request failed:', error);
    }
}

// Example usage
checkURL('https://example.com');
Python (requests)

import requests
import json

def check_url(url, base_url='http://localhost:5000'):
    """Check if a URL is phishing using the PhishGuard API."""
    
    endpoint = f"{base_url}/api/predict"
    payload = {"url": url}
    
    try:
        response = requests.post(
            endpoint, 
            json=payload,
            headers={'Content-Type': 'application/json'}
        )
        
        result = response.json()
        
        if result['success']:
            prediction = result['data']['prediction']
            confidence = result['data']['confidence']
            print(f"URL: {url}")
            print(f"Prediction: {prediction}")
            print(f"Confidence: {confidence:.4f}")
            return result['data']
        else:
            print(f"Error: {result['error']}")
            return None
            
    except Exception as e:
        print(f"Request failed: {e}")
        return None

# Example usage
result = check_url('https://example.com')
cURL

# Single URL prediction
curl -X POST "http://localhost:5000/api/predict" \
     -H "Content-Type: application/json" \
     -d '{"url": "https://example.com"}'

# Batch prediction
curl -X POST "http://localhost:5000/api/predict/batch" \
     -H "Content-Type: application/json" \
     -d '{"urls": ["https://example.com", "https://suspicious-site.tk"]}'

# Get model info
curl "http://localhost:5000/api/model/info"

Rate Limits

Current rate limits:

  • Single predictions: No limit
  • Batch predictions: Maximum 100 URLs per request
  • Training: Minimum 10 samples required
For production deployments, implement appropriate rate limiting based on your needs.

Error Handling

All API responses follow a consistent format:

Success Response:
{
  "success": true,
  "data": {
    // Response data here
  }
}
Error Response:
{
  "success": false,
  "error": "Error message description"
}
Best Practice: Always check the success field before processing the response data.

REST API

Integration reference

POST /api/predict

curl -X POST http://localhost:5000/api/predict \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com"}'

POST /api/predict/batch

Accepts a JSON array of up to 500 URLs.

{"urls":["https://example.com","http://198.51.100.42/login"]}

GET /api/health

Returns application status and active model information.
